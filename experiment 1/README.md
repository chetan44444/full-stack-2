# Dynamic Post Composer – Experiment 1

## Aim
To design and develop a dynamic post composer interface supporting multiple platforms with constraint validation.

## Features
- Select/deselect multiple social media platforms
- Platform-specific character limits
- Real-time character counters
- Instant validation messages
- Live post preview
- Optional media URL
- Responsive UI
- Publish button disabled when validation fails

## Requirements
- Node.js
- npm
- VS Code
- Chrome/Edge

## How to run

1. Open this folder in VS Code.
2. Open the terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the localhost URL shown by Vite.

## Experiment Procedure
1. Create the React post composer.
2. Select one or more platforms.
3. Enter post content.
4. Observe character counts.
5. Enter content beyond a platform's limit to see validation.
6. Correct the content and observe the Publish button becoming enabled.
7. Resize the browser to verify responsive design.

## Learning Outcomes
- Multi-platform content handling
- React state management
- Real-time validation
- Conditional rendering
- Responsive component design
